# STM32-Based Smart Car Parking System (Arduino IDE Implementation)

## Project Overview
This project is a smart embedded system developed using an STM32 microcontroller for automated parking slot detection and monitoring. The system detects vehicle entry and exit using sensors and updates slot availability in real time. The firmware is implemented using Arduino IDE for rapid development and prototyping.

---

## Features
- Real-time vehicle detection using IR or ultrasonic sensors  
- STM32-based GPIO interfacing  
- Slot availability monitoring system  
- Interrupt or polling-based response handling  
- LED or buzzer indication for parking status  
- Embedded firmware developed using Arduino IDE  

---

## Working Principle
- Sensors detect vehicle entry or exit  
- STM32 reads sensor input through GPIO pins  
- Firmware processes input logic  
- Slot counter is updated accordingly  
- Output indicators display parking status  

---

## System Architecture
Sensor Input → STM32 GPIO → Logic Processing → Slot Counter Update → Output Indicators
